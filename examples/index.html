folio examples

Built from dist/. Run pnpm build first if these 404.

  • The drop-in — one script tag, no code. The page paginates itself on load. This is the Paged.js replacement path.
  • The Previewer — one call from inside an application: paginate a hidden manuscript into a preview pane when a button is pressed. A table of contents with dot leaders, a footnote and a cross-reference.
  • Mathematics — MathML laid out by the browser from the font's MATH table, with the paged part added: numbered equations that restart per chapter, references by number and page, an equation too wide for the line broken at its operators, a formula in the running head and one in a footnote.
  • Mathematics in LaTeX — the same book written with \( … \), \[ … \], \begin{equation}, \label and \eqref, as for MathJax. One more script tag turns it into MathML before the engine measures; the pages come out the same.
  • A technical report — text, mathematics and tables in a sans family (IBM Plex Sans with Noto Sans Math, served from examples/fonts/): numbered equations, a table with formulas in it, a long table split across pages with its header repeated, tables and equations referred to by number and page, a footnote.
  • The same report in Noto Sans — nothing changed but the text face: Noto Sans with Noto Sans Math, drawn as one family, so the formulas sit at the text's own size.
  • The library and the viewer — paginate under your own control and show the result with spreads, zoom and page navigation.
